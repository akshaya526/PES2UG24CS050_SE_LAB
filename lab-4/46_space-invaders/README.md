## Project Overview
A Python and Pygame-based Space Invaders game enhanced as part of the SE Lab 4 VibeCoding assignment.

## Features Implemented
- Fixed and balanced enemy bullet firing.
- Improved bullet-enemy collision detection.
- Game Over screen displaying the final score.
- Easy, Medium, and Hard difficulty levels.
- Replay and exit options.
- Sound effects for firing, enemy destruction, and Game Over.

## Technologies Used
- Python
- Pygame

## How to Run
Install the required dependencies and run:

```bash
python -m pip install -r requirements.txt
python main.py
```
